# Mavie Jewelry — Portfolio Project

This is a front-end concept build for a fictional jewelry brand, **Mavie Jewelry**. I built it as a
personal/portfolio project to practice designing and coding a full e-commerce style website — homepage,
product pages, cart, account flows, and legal/info pages — using plain HTML, CSS, and jQuery.

## What this is (and isn't)

Mavie Jewelry is **not a real company**. There's no real store behind this site, and none of the products,
prices, or policies are meant to be taken as an actual business offer. All company details (name, address,
email, phone number, and policies) are fictional and included purely to make the demo feel complete.

This project exists to showcase front-end development and UI/UX work — layout, responsiveness, product
card interactions (like the gold/silver variant switcher), cart and account flows, and general site
structure — not to sell anything.
